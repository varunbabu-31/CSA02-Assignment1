# CSA02 - Assignment 1

## C Programming: Electricity Billing System

This project implements and analyses a rural electricity billing system using C programming.

## Project Contents

- `C Programming Assignment 1.docx`: Assignment report
- `task_2.c` to `task_12.c`: C source files for the completed programming tasks, where applicable
- `billing.h`: Header file for billing constants and function declarations

## Main Features

- Meter reading and electricity consumption calculations
- Tariff slabs and fixed charges
- Data types, constants, and macros
- Formatted input and output
- Type conversion and precision analysis
- Compilation and testing
- Smart-meter peak-hour tariff design

## How to Compile and Run

Install a C compiler such as GCC. Open a terminal in the project folder and compile an individual source file:

```bash
gcc task_2.c -o task_2
```

Run it on Windows:

```bash
task_2.exe
```

Some tasks may require additional source files or the header file `billing.h`. Compile all required source files together when necessary.
